
# Bloodborne (EU, GoTY)
`CUSA03173`

## Percorso del file di salvataggio
Cartella nella quale andranno tutte le cose di [data](./data)
- Windows: `%appdata%/shadPS4/home/1000/savedata/CUSA00207`
> Dal nuovo aggiornamento di ShadPS4 salva sulla cartella della versione Americana (Credo sia un bug)

## Percorso del file dei trofei
Cartella nella quale va [NPWR05818_00.xml](./NPWR05818_00.xml)
- Windows: `%appdata%/shadPS4/home/1000/trophy`

## Percorso della cartella di configurazione di ShadPS4
Cartella nella quale andranno tutte le cose di [config](./config) se reinstalli ShadPS4
- Windows: `%appdata%/shadPS4`
> La chiave dei trofei è probabilmente quella di uno che aveva Bloodborne e, se fosse questo il caso, non funzionerebbe con i giochi che il proprietario non possiede/possedeva
